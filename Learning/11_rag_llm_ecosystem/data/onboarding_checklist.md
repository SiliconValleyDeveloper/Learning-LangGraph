# Onboarding Checklist

## Day 1

1. Clone the repository
2. Create `.venv` and install `requirements.txt`
3. Copy `.env.example` to `.env`
4. Pull Ollama models for chat and embeddings
5. Start API on port 8000 and UI on port 4200

## Day 2

1. Run Phase 11 lessons in order
2. Open the RAG visualizer from the sidebar
3. Ask a grounded question and inspect retrieved chunks
4. Add one private note file under `data/private/` and restart the API

## Day 3

1. Compare public vs private source labels in the evidence panel
2. Change one public document and verify the answer changes after API reload
3. Write a short summary of when RAG should refuse an answer
